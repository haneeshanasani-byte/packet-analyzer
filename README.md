# Smart Network Packet Analyzer

## Description
This project captures live network packets and analyzes them to detect suspicious activity.

## Features
- Packet sniffing using Scapy
- Protocol detection (TCP, UDP, ICMP)
- Suspicious traffic alert system
- Logs saved in logs.txt

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python main.py
